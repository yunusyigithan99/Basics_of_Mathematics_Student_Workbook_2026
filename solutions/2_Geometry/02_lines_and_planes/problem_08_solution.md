# Problem 8 Solution: Intersection Point of a Line and a Plane

## 1. Original Problem
Find the coordinates of the intersection point of the line
$$L : (x, y, z) = (1, 0, 2) + t(1, 2, -1), \quad t \in \mathbb{R}$$
with the plane
$$\Pi : x + y + z = 4.$$
Check the result by substituting the resulting point back into both the line and the plane descriptions.

---

## 2. What We Are Trying to Find
We need to:
1. Express the coordinates $x(t), y(t), z(t)$ of any point on the line in terms of the single parameter $t$.
2. Substitute these parametric expressions into the plane equation to find the unique parameter value $t^*$ at the point of intersection.
3. Compute the Cartesian coordinates of the intersection point $I$.
4. Check that point $I$ satisfies the plane equation.
5. Check that point $I$ is generated by the line equation.

---

## 3. Key Concepts and Theorems
1. **Intersection of a Line and a Plane:**
   A line $L : X(t) = P_0 + t\,v$ intersects a plane $\Pi : n \cdot X = d$ at a unique point if and only if the line is not parallel to the plane, which occurs when:
   $$v \cdot n \neq 0.$$
2. **Solving by Substitution:**
   Substituting the coordinate components $x(t), y(t), z(t)$ into the linear plane equation yields a single linear equation in $t$:
   $$n \cdot (P_0 + t\,v) = d \implies n \cdot P_0 + t(n \cdot v) = d \implies t = \frac{d - n \cdot P_0}{v \cdot n}.$$
   Plugging this value of $t$ back into the line equation yields the exact intersection point coordinates.

---

## 4. Detailed Step-by-Step Solution

### Step 1: Write Parametric Equations for the Line
From $(x, y, z) = (1, 0, 2) + t(1, 2, -1)$, write the individual coordinate functions:
$$\begin{cases}
x(t) = 1 + t \\
y(t) = 2t \\
z(t) = 2 - t
\end{cases}$$

### Step 2: Substitute into the Plane Equation
Substitute $x(t), y(t), z(t)$ into the equation of the plane $x + y + z = 4$:
$$(1 + t) + (2t) + (2 - t) = 4.$$

### Step 3: Solve for the Parameter $t$
Group the constant terms and the $t$ terms:
$$(1 + 2) + (t + 2t - t) = 4$$
$$3 + 2t = 4.$$
Subtract 3 from both sides:
$$2t = 1 \implies t = \frac{1}{2}.$$

### Step 4: Compute the Coordinates of the Intersection Point
Substitute $t = \frac{1}{2}$ back into the parametric equations:
$$x = 1 + \frac{1}{2} = \frac{3}{2},$$
$$y = 2\left(\frac{1}{2}\right) = 1,$$
$$z = 2 - \frac{1}{2} = \frac{3}{2}.$$
Thus, the intersection point is:
$$I = \left(\frac{3}{2}, \; 1, \; \frac{3}{2}\right) = (1.5, \; 1, \; 1.5).$$

### Step 5: Check in Both Descriptions
1. **Check in the plane equation:**
   Substitute the coordinates of $I$ into $x + y + z = 4$:
   $$\text{LHS} = \frac{3}{2} + 1 + \frac{3}{2} = \left(\frac{3}{2} + \frac{3}{2}\right) + 1 = 3 + 1 = 4.$$
   $$\text{RHS} = 4.$$
   The point lies on the plane $\Pi$.
2. **Check in the line equation:**
   Subtract the base point $P_0(1, 0, 2)$ from $I$:
   $$I - P_0 = \left(\frac{3}{2} - 1, \; 1 - 0, \; \frac{3}{2} - 2\right) = \left(\frac{1}{2}, \; 1, \; -\frac{1}{2}\right).$$
   Factoring out the scalar $\frac{1}{2}$:
   $$\left(\frac{1}{2}, \; 1, \; -\frac{1}{2}\right) = \frac{1}{2}(1, 2, -1) = \frac{1}{2}v.$$
   This corresponds exactly to parameter value $t = \frac{1}{2}$ along direction vector $v$.
   The point lies on the line $L$.

---

## 5. Why Each Step Is Valid
1. **Parametric representation** guarantees that every point computed lies on the line.
2. **Substituting into the plane equation** enforces the constraint that the point must simultaneously belong to the plane.
3. **Because the coefficient of $t$ is $2 \neq 0$**, the solution $t = 1/2$ is unique, guaranteeing a single point of transverse intersection.

---

## 6. Final Answer in Words
The intersection point of the line and the plane is $I = \left(\frac{3}{2}, 1, \frac{3}{2}\right)$ or $(1.5, 1, 1.5)$, corresponding to parameter value $t = \frac{1}{2}$. Substituting into the plane equation gives $\frac{3}{2} + 1 + \frac{3}{2} = 4$, and substituting into the line equation confirms that $I = (1, 0, 2) + \frac{1}{2}(1, 2, -1)$, verifying that the point lies on both geometric objects.

---

## 7. Quick Verification
- **Dot product formula check:**
  Base point $P_0 = (1, 0, 2)$, direction $v = (1, 2, -1)$, normal $n = (1, 1, 1)$, constant $d = 4$.
  $$n \cdot P_0 = 1(1) + 1(0) + 1(2) = 3.$$
  $$v \cdot n = 1(1) + 2(1) + (-1)(1) = 1 + 2 - 1 = 2.$$
  $$t = \frac{d - n \cdot P_0}{v \cdot n} = \frac{4 - 3}{2} = \frac{1}{2}.$$
  This immediately verifies $t = 1/2$ through vector projections.

---

## 8. Common Mistakes to Avoid
- **Algebraic error in combining $t$ terms:** Writing $t + 2t - t = 4t$ instead of $2t$.
- **Fraction subtraction error:** Calculating $2 - 1/2 = 1/2$ instead of $3/2$.
- **Stopping at $t = 1/2$:** Stating that the intersection is $t = 1/2$ rather than providing the actual spatial coordinates $(x, y, z)$.

---

## 9. Classroom Presentation (3-Sentence Summary)
We substitute the line's parametric coordinate equations $(1+t, 2t, 2-t)$ directly into the plane's equation $x+y+z=4$, yielding the simple linear equation $3 + 2t = 4$. Solving gives the parameter value $t = 1/2$, which produces the intersection point coordinates $(3/2, 1, 3/2)$. We confirm the solution by showing that the sum of these coordinates equals $4$ and that subtracting the base point recovers half the line's direction vector.
